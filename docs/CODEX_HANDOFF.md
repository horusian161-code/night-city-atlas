# RED CITY — продолжение разработки в Codex

## Задача пользователя

Доработать модуль интерактивной карты Найт-Сити 2045 для **Cyberpunk RED / Foundry VTT v12** до проверяемой рабочей версии. Первый приоритет: пользователь сообщает, что установка через manifest не скачивает модуль. Причина пока не установлена. Требуется исправление в коде или публикации, а не только инструкция по ручной установке.

Исходное требование: места города обозначены на карте; район подсвечивается при наведении и показывает краткую сводку с картинками. Интерфейс прежде всего русский.

## Что реализовано

- Отдельное окно атласа на API Foundry v12: `Application`, launcher на `FormApplication`; системный ID `cyberpunk-red-core`.
- 24 района, 24 оригинальные SVG-иллюстрации, авторская схематическая SVG-карта 1600×2473.
- 156 отметок из бесплатного официального **Night City Atlas v1.01 (январь 2025)**: 155 разных мест, поскольку Forlorn Hope показан до и после переноса.
- Подсветка и карточка района при наведении; выбор района и карточек мест; поиск RU/EN, 8 категорий, фильтры районов, zoom/pan и клавиатура; адаптивный UI.
- Метки кампании, редактирование GM, импорт/экспорт JSON, ссылки на Journal UUID с проверкой прав, явная отправка карточки в чат.
- Общие метки хранятся в world setting; личные метки GM — отдельно в client storage для пары world/user. Проверять, что личные данные не попадают в общий setting, API игрока, чат или общий экспорт.
- Нет внешних runtime-зависимостей, CDN и сетевых запросов для встроенных изображений. При активации не изменяются сцены, актёры или предметы.

## Граница данных

Текущий атлас не содержит все 600+ мест платного справочника **Night City 2045 (2026)**. Не заявлять полное покрытие города при наличии только бесплатного Atlas. Не добавлять географию и заведения 2077 года в 2045. Не перепубликовывать исходные защищённые PDF/карты. Расширение базы допускается на основе законно доступных источников и пользовательских данных с указанием источника и приблизительности координат.

Для B4 Garden of Earthly Delights сохранено расхождение: каталог относит место к Upper Marina, исходная отметка расположена возле Kabuki. `placementNote` должен оставаться видимым.

## Порядок доработки

1. **Воспроизвести установку через manifest.** Проверить публичные HTTP-ответы без cookies/авторизации из обычного Node/Python/curl и из сервера Foundry, если доступен. Зафиксировать status, final URL, MIME, тело JSON, redirect chain и ошибку установщика. Проверить raw manifest, release asset manifest и URL ZIP из JSON. Не выдавать предположение о сети, кэше или схеме за найденную причину.
2. **Проверить manifest именно по Foundry v12.** `compatibility`, `relationships`, обязательные поля и диапазон сборок, соответствие ID/версии manifest в main, релизе и ZIP. Значение `verified` добавлять только после настоящей проверки указанной сборки. Проверить структуру распаковки и наличие каждого пути `esmodules`/`styles`/`templates`/`data`/`assets`.
3. **Исправить сборку и публикацию.** Сделать воспроизводимый release workflow: тесты → пакет → проверка структуры ZIP → публикация ZIP и module.json → проверка публичного скачивания. `.github` и `dist` уже исключены в `tools/package.py`; не допустить вложения предыдущего ZIP в новую сборку. При исправлениях выпустить следующую patch-версию, согласовать manifest/version/tag/download. Не перезаписывать опубликованный tag без необходимости.
4. **Проверить интеграцию Foundry v12.** Активация, открытие через token controls / журналы / settings / Alt+Shift+N; повторное открытие и закрытие; отсутствие ошибок console; установка в чистый тестовый мир Cyberpunk RED. Рабочие миры пользователя и их документы не изменять. Если ядро или доступ недоступны, честно указать конкретный непроверенный пункт.
5. **Довести карту и карточки.** Проверить все 24 полигона: hover/focus highlight, картинка и текст, выбор и снятие выбора. Проверить все точки и совпадение данных с бесплатным Atlas, фильтрацию, поиск кириллицы, zoom/pan, отсутствие перекрытия важного UI, работу маленького окна. Исправлять реальные ошибки, сохраняя стилистику RED CITY.
6. **Проверить права и сохранение.** GM/player, private/public pins, обновление общего окна между участниками, импорт ошибочного JSON без частичной записи, сохранность пользовательских меток после обновления модуля, Journal permission checks. Импортированный HTML/скрипты не исполнять.
7. **Передать результат.** Реальные исправления, соответствующие им проверки, PR/commit, готовый релиз и рабочий Manifest URL. В отчёте отдельно перечислить то, что проверено в живом Foundry, и то, что осталось без проверки.

## Файлы и команды

- `module.json` — manifest установки.
- `scripts/foundry.js` — adapter Foundry, hooks, settings, launcher и GM UI.
- `scripts/atlas-ui.js`, `styles/atlas.css`, `styles/foundry.css` — окно и взаимодействия.
- `scripts/model.js` — модель, merge/import/validation.
- `data/atlas.json`, `assets/map-base.svg`, `assets/districts/` — география, точки, иллюстрации.
- `templates/`, `tests/`, `tools/package.py` — шаблоны, проверки, сборка.
- `docs/VALIDATION.md`, `docs/COVERAGE.md`, `docs/SOURCES.md` — проверки, покрытие и источники.
- `preview.html` — демо через локальный HTTP; `preview-offline.html` — самодостаточное демо, не сохранение в мир Foundry.

Из корня checkout: `npm test`, затем `npm run build`. Нужны Node.js 20+ и Python 3.10+; установка npm-зависимостей модуля не требуется. Пакет создаётся рядом с каталогом checkout. Для web preview: `python3 -m http.server 8000`, затем открыть `/preview.html`.

## Критерии готовности

- Foundry v12 устанавливает модуль по выданному Manifest URL, скачивая публичный ZIP без авторизации; если это невозможно воспроизвести, причина и граница проверки явно указаны.
- Код, ZIP и manifest имеют согласованную версию; runtime-файлы присутствуют после установки.
- Модуль открывается в Cyberpunk RED, подсветка районов и карточки с изображениями работают, нет ошибок console.
- Базовые автоматические проверки проходят; дополнены только необходимые проверки для найденных дефектов.
- Не повреждены документы мира и пользовательские метки; личные метки GM не раскрываются игрокам.
- Опубликован конкретный готовый результат и указаны реальные ограничения покрытия и проверки.
