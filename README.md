# RED CITY // 2045

Интерактивная карта Найт-Сити 2045 для **Foundry VTT v12** и системы **Cyberpunk RED (`cyberpunk-red-core`)**. Отдельное окно: районы подсвечиваются, при наведении появляются краткая сводка и иллюстрация; места открывают карточки. Вся базовая информация и изображения поставляются вместе с модулем.

## Установка

В Foundry откройте **Add-on Modules → Install Module** и вставьте в поле **Manifest URL**:

```text
https://raw.githubusercontent.com/horusian161-code/night-city-atlas/main/module.json
```

Нажмите **Install**, затем включите модуль в мире Cyberpunk RED. После активации перезагрузите мир. ZIP также доступен в [релизе v1.0.0](https://github.com/horusian161-code/night-city-atlas/releases/tag/v1.0.0).

Ручная установка из ZIP:

1. Полностью остановите Foundry.
2. Распакуйте папку **`night-city-atlas`** из ZIP в каталог **`Data/modules`** вашего Foundry User Data. Итоговый путь: `Data/modules/night-city-atlas/module.json`. Не создавайте вторую вложенную папку с таким же именем.
3. Запустите Foundry, откройте мир с системой Cyberpunk RED, выберите **Manage Modules / Управление модулями** и включите **RED CITY — Interactive atlas for Cyberpunk RED**.
4. Откройте карту кнопкой с иконкой карты в инструментах токенов либо кнопкой **Найт-Сити** в разделе журналов. Ещё один путь: **Настройки → Настройки модулей → RED CITY → Открыть карту**.

Горячая клавиша по умолчанию: **Alt + Shift + N**. Её можно переназначить в настройках клавиш Foundry. Перезагрузка мира после активации модуля обязательна.

## Использование

- **Наведение на район:** подсветка границ, изображение и краткая сводка.
- **Щелчок по району:** закрепляет район и открывает его справку.
- **Щелчок по точке:** карточка места, район, категория, источник и точность координат.
- **Поиск:** по русскому и английскому названию, описанию и районной принадлежности. Категории позволяют убрать лишние точки.
- **Колесо мыши / кнопки + и −:** масштаб. Перетаскивание карты: перемещение. Кнопка сброса возвращает общий вид.
- **Клавиатура:** Tab переводит фокус, Enter или пробел выбирает район/точку. Кнопки имеют подписи.
- **Мастер:** создаёт и редактирует точки, выбирает собственные изображения через File Picker, импортирует JSON и выгружает резервную копию. В панели карточки можно открыть привязанный журнал или отправить общедоступную карточку в чат.

Описания импортированных точек отображаются как обычный текст. HTML и скрипты в описаниях не исполняются. Журналы открываются только при наличии прав чтения.

## Что входит в карту

Основой служит бесплатный **Night City Atlas v1.01** издателя R. Talsorian Games, январь 2025 года: география 2045 года, 24 района и каталог мест из опубликованных к тому времени материалов. База не переносит географию и заведения 2077 года в 2045 год.

**Это схематическая карта для ориентации и игры.** Контуры берегов, улицы и границы районов перерисованы; дорожная сетка условная. Координаты канонических точек сверены с Atlas, но после ручного переноса остаются приблизительными. Карта не рассчитана на измерение реальных дистанций или автоматический расчёт маршрутов. Иллюстрации — авторские векторные образы районов, не официальные изображения конкретных зданий.

Полный справочник **Night City 2045**, выпущенный в июне 2026 года, содержит **более 600 мест**. Он не приложен и не воспроизведён в этом модуле. Бесплатный Atlas представляет более ранний, ограниченный срез. Для расширения используйте собственные точки и импорт материалов вашей кампании. Число записей и конкретная граница покрытия указаны в окне карты и `docs/COVERAGE.md`.

Официальный Atlas: https://rtalsoriangames.com/2025/01/15/cyberpunk-red-alert-january-2025-dlc-night-city-atlas/

Актуальный справочник: https://rtalsoriangames.com/night-city-2045/

## Метки кампании и личные заметки

Общедоступные метки и изменения базовых точек сохраняются в настройках этого мира. Обновление файлов модуля их не удаляет. Изменения становятся видны открытым окнам других участников.

**Личная метка GM** хранится отдельно в браузере мастера для пары «мир / пользователь»; она не передаётся в общие настройки или чат. Она не синхронизируется между устройствами. Для переноса на другой компьютер используйте **Полная копия с личными метками** и импортируйте её там. Другие пользователи того же физического браузера имеют доступ к его локальному хранилищу, поэтому для разных пользователей используйте разные профили браузера.

Удалённая базовая точка скрывается только в вашей кампании; исходный каталог остаётся в файлах модуля. Она может быть возвращена импортом записи с её ID в массив `overrides`. Пользовательская точка удаляется из настроек. Экспортируйте копию до массовых изменений.

## Импорт

Импорт принимает один JSON-файл размером до 2 МБ. Максимум — 2000 пользовательских точек. Импорт добавляет новые записи и обновляет существующие по `id`; он не удаляет другие метки. Сначала проверяется весь файл, и только затем данные записываются.

Минимальный формат приведён в `docs/import-example.json`. Используйте реальные `districtId` из `data/atlas.json`; координаты выражаются в единицах внутренней карты (`width` и `height` из того же файла). `hidden: true` означает личную метку GM. Категории: `nightlife`, `medical`, `corporate`, `civic`, `transport`, `market`, `landmark`, `gang`.

Для изменения базового места используйте полный объект метки в массиве `overrides`. Его ID должен совпадать с базовым. Массив `disabled` содержит ID базовых мест, скрытых в кампании. Полный экспорт включает все три массива.

Изображения: локальный путь Foundry, например `worlds/my-world/images/clinic.webp`, либо HTTPS URL. Изображения из внешних URL требуют сети; встроенные картинки работают локально. `journalUUID` принимает UUID JournalEntry или JournalEntryPage. Названия и описания заполняются своим текстом.

## Макросы и расширение

Открыть карту:

```js
game.modules.get("night-city-atlas").api.open();
```

Открыть район или точку:

```js
game.modules.get("night-city-atlas").api.open({type: "district", id: "n"});
// Идентификаторы берите из data/atlas.json.
```

Получить доступный текущему пользователю каталог:

```js
const atlas = await game.modules.get("night-city-atlas").api.getData();
```

GM API: `addLocation(point)` и `importLocations(payload)` возвращают Promise и проверяют права пользователя и формат данных. В API нет методов изменения сцен, актёров, предметов или правил системы.

## Проверка и ограничения

Модуль использует API **Foundry v12**, `Application`, `FormApplication` и массив инструментов `getSceneControlButtons`. Для v13/v14 он не объявляет совместимость. Внешние модули и библиотеки не требуются.

Автоматические проверки и визуальная проверка отдельного интерфейса описаны в `docs/VALIDATION.md`. Эти проверки не заменяют запуск в настоящем Foundry v12: в среде сборки нет лицензированного серверного ядра Foundry. Перед игровой сессией пройдите короткую проверку из этого файла в своём тестовом мире.

Модуль создаёт только свои настройки. Он не заменяет canvas, не импортирует сцены и не обновляет документы мира при активации. Отправка карточки в чат происходит по явному нажатию мастера.

## Разработка

Node.js 20+ и Python 3.10+. Установка npm-пакетов не нужна.

```sh
npm test
npm run build
```

Сборка создаёт `red-city-night-city-atlas-v1.0.0.zip` рядом с папкой проекта. `preview-offline.html` внутри пакета позволяет открыть тот же интерфейс без Foundry; это демонстрация, её изменения не сохраняются в мир. Обычный `preview.html` можно запустить через `python3 -m http.server 8000` из папки модуля и открыть `http://localhost:8000/preview.html`.
